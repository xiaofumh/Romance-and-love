# V0.4.3：北京时间与12轮研发

服务器按UTC+8提供Asia/Shanghai时间，本轮模型系统消息使用服务器时钟；用户文本、角色资料和历史引用不能覆盖它。当前窗口的每条历史另附应用记录的北京时间索引，用来区分消息当时的“昨天／明天”和本轮日期，不把引用或剧情年份当成现实日期，也不根据时间推断天气、地点和用户活动。没有自动保存新日程或改写事实记忆。

聊天页显示“北京时间 · 服务器最近同步”；本地演示标为本机时间。显示的是加载时刻，不是持续更新的实时钟表。新用户消息时间按服务端请求开始时记录，AI消息按完成时记录；旧消息原时间不批量改写。服务器时钟仍依赖部署环境时间正确，没有独立授时服务承诺。

12轮实验模式改为按最近12条用户消息分组，保留对应普通回复及每轮最多一次主动接话，最多36条语义消息。气泡分段不占轮数。原6轮模式仍按最多12条近期消息截取，不批量迁移既有会话，不自动取消实验标识。每条历史仍最多600字符、正文最多40条／30天，记忆和参考上限不变；纠错、记忆停用、删除、过期仍优先，不能为了凑满12轮越过这些边界。

因此，12轮不是无限上下文，也不保证长消息尾部完整发送或事实必然正确。增加历史时间轴和消息数量会增加输入体积与延迟可能性；内测1000轮、全站300000次、访问白名单和密钥保持不变。

本地验证包含UTC跨北京时间零点、闰日、客户端伪造时间字段拒绝、可信时钟与历史年份区分、主动消息不挤占12个用户轮次，以及40条存储截断后的完整服务流程。跨天、最多36条并含每轮主动消息的边界使用固定时间／模型模拟，不冒充真实跨午夜或连续多次五分钟冷却验收。真实模型结果另保留独立JSON。

V0.4.2独立快照保留，本轮另存V0.4.3。源码回溯不等于数据恢复或自动回退云配置。未公开发布，12轮继续作为研发／实验选项。
