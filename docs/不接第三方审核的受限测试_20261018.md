# 不接第三方内容审核的开发测试

本轮用户决定暂不接第三方内容审核，继续开发；随后要求不展示“内部测试模式”标签。此处记录技术配置和测试边界，不是公开上线许可。

## 已实现

- 新增服务端 `internal-test` 策略，不调用 TMS。保留原有 `tms` 策略作为默认；配置缺失、SDK/网络错误、非 Pass 的结果都不会自动跳过。
- 跳过外部检查需要同时显式配置两个服务端开关，并将当前微信身份对应的独立接入标识加入白名单。白名单留空时无人可发起新生成；最多20个账号，不支持通配符。该上限是项目的开发限制，不是法规人数阈值。
- 接入标识由可信微信上下文确定，再用不同域的 HMAC 派生；不返回 OPENID、数据库用户 UID、密钥或完整名单。客户端携带的身份/开关不能赋予权限。
- 限制适用于陪伴聊天和旧版回复建议。本人已有数据仍可查看、导出或删除，不因失去生成权限而被锁住。
- 保留用户/角色隔离、手动授权、记忆开关、全站调用预算、个人额度、幂等、超时和删除/撤回取消逻辑。
- 聊天页和会话列表不显示“内部测试模式”标签；保留 AI 身份提示。未接第三方审核以及仍向模型服务商发送数据的事实在隐私页说明。“我的 → 模型连接”可手动复制本人接入标识。
- 模型未开启或账号未授权时，发送按钮不可用，草稿保留；没有自动接受授权、开启保存或改为云模式。

## 云端接入步骤（尚未执行）

在 `assistantApiV2` 的服务端配置中操作，客户端 `.env.example` 不会自动同步到云端：

1. 先部署本次函数代码；保持 `ASSISTANT_ENABLED=false`。
2. 将 `ASSISTANT_RELEASE_STAGE=internal-test`、`CONTENT_REVIEW_MODE=internal-test`。`INTERNAL_TEST_USER_IDS` 先留空，此时无人可生成；TMS 凭证不需要填写。不要为此更改现有用户哈希密钥或数据库权限。
3. 在小程序“我的 → 运行模式”手动切换云端，再在“模型连接”手动复制本账号接入标识。标识不是密钥，但仍按账号相关信息保管，不公开传播。
4. 维护者把接入标识加入服务端 `INTERNAL_TEST_USER_IDS`，多个标识以逗号分隔。错误/空白名单不能赋予权限。环境变量更新后须确保新配置实例生效。
5. 确认服务端新模型密钥、所需数据库配置与成本预算，再开启 `ASSISTANT_ENABLED=true`。建议先以全站10次/单用户5次做小规模合成内容冒烟。开关为 true 不代表密钥/模型网络已经验证通过。
6. 用户自行确认说明和聊天保存后先发少量合成内容，核验真实 wx 身份、预算事务、GLM 响应与幂等；通过后才增加测试量。不要将本地 mocked 测试冒充这一结果。

以上新增服务端变量尚未代填，未启用付费调用。原 `tms` 路径仍可用，但公开服务前应独立完成适用的安全措施、评估/备案和平台审核，不是把阶段改成 production 就完成上线。

## 验证与限制

本地类型检查、构建、97项测试、15页入口及前端边界检查通过。新增15项覆盖空名单/错误阶段/非法模式、可信身份、未授权账号、两条生成路径、外部审核失败关闭、单次调用与幂等、费用预算、无权限时数据导出删除以及前端交互、模型关闭后原请求查询。

云 SDK、数据库及模型传输在新增测试中使用明确标注的替身；未进行本次真实 GLM 调用、云端新配置验收或完整50轮测试。真实微信双账号隔离、数据库客户端规则和定时清理仍未完成，不扩大此前 startup 成功结论。

外部审核跳过逻辑本身不识别危险内容，也不保证模型自带过滤有效；只用于受限开发验证。日志和报告不得记录密钥、OPENID、私人正文或白名单。
