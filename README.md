# Romance and Love · 相伴 AI 小程序

微信式聊天界面的 AI 朋友／伴侣角色小程序，当前源码版本 **V0.7.0-dev.1**（研发版，尚未替换已部署V0.5.3）。使用原生微信小程序、TypeScript、微信云开发及智谱 BigModel GLM-4.7。

## 当前功能

- 选择人格、称呼、关系及表达习惯，以角色口吻进行多轮聊天。
- 默认最近12轮用户消息及对应回复，包含每轮至多一条主动消息，最多36条历史语义消息；可选择6轮精简模式。每条历史仍最多600个JavaScript长度单位，纠错、删除、过期和记忆关闭边界优先。
- 根据当前对话承接、延伸、转场或收尾，聊天页不需要选择相处模式。角色主动开关默认关闭；旧模式仍仅前台；明确开启新版后可使用后台自主机制（需实际部署触发器并验收），尊重暂停、草稿和拒绝话题，并允许等待。
- TXT／粘贴历史参考的本地解析与清洗；文件最多1MB，不另设字数限制。历史示例仅作相关参考和表达风格材料，不自动变成当前用户事实。
- 可核对、确认、纠正、删除的结构化事实记忆，以及按用户、角色、会话隔离的上下文。
- 可选聊天截图转写，使用GLM-4.6V-FlashX；上传前确认并核对结果。
- 服务端北京时间、请求幂等、访问控制、调用额度及用量记录。模型密钥只在服务端。

## 本地构建

需要Node.js 20+及pnpm。克隆仓库后在项目根目录运行：

```powershell
pnpm install --frozen-lockfile
pnpm check
```

`pnpm check`执行类型检查、构建、离线自动化测试和前端边界检查，不调用付费模型。构建生成`dist/miniprogram`及`dist/cloudfunctions`；`dist`不提交到Git。

在微信开发者工具导入**项目根目录**。`project.config.json`将入口指向`dist/miniprogram/`，因此需先构建。

## 云端接入

当前仓库保留该工程的公开AppID和云环境标识，位于`project.config.json`及`src/miniprogram/config.ts`；它们不是授权密钥。实测脚本也校验同一工程。改用其他小程序时需统一更新这些标识及对应路由测试。

将模型密钥、用户标识哈希密钥、额度和访问策略配置到云函数环境变量。变量名与空白密钥示例见[.env.example](.env.example)。此文件只是配置模板，部署脚本不会自动把它加载进云端。不要提交实际`.env`、AppSecret、密钥或私人聊天数据。

构建后，将`dist/cloudfunctions/assistantApiV2`部署到自己的微信云开发环境，按需要部署`assistantCleanup`。客户端不能直接持有模型密钥；生成仍需通过服务端身份、授权和访问策略检查。

服务端模板默认关闭生成。内测访问配置和外部审核策略的含义见[云端配置说明](docs/云端部署与配置清单_20261018.md)及[受限测试说明](docs/不接第三方审核的受限测试_20261018.md)。代码上传GitHub不等于小程序已通过微信审核或公开发布。
