# V0.1 真实模型接入与验收

更新：2026-10-18。已确认使用智谱 BigModel 国内官方 GLM-4.7，完成独立真实接口诊断；项目结构校验发现异常后已强化提示词，尚未进行修订后真实复测。未部署云端，未完成小程序全链路或真机联调。

## 一、需要你提供或自行填写的项目

| 项目 | 填写位置 | 是否可发给开发者 |
| --- | --- | --- |
| 企业小程序 AppID | 根目录 project.config.json | 可提供，属于公开标识 |
| CloudBase 环境 ID | src/miniprogram/config.ts 的 cloudEnvId | 可提供，是环境标识 |
| 模型服务地址、名称 | 云函数环境变量 | 可提供非密钥部分 |
| 模型 API Key | 云函数环境变量 MODEL_API_KEY | 不发到聊天或前端 |
| 腾讯云文本审核凭证、策略 | 云函数环境变量 | 密钥仅服务端填写 |
| 用户标识哈希密钥 | 云函数环境变量 ASSISTANT_USER_HASH_SECRET | 随机生成至少32字符，妥善保管，不发送 |
| 实际运营主体及联系渠道 | 云函数环境变量 | 按真实情况填写 |

`ASSISTANT_USER_HASH_SECRET` 用来将可信微信身份映射为内部不可直接识别的ID。更换它会改变用户映射，禁止未经迁移直接轮换导致旧数据失联。

## 二、云环境准备

1. 使用实际企业主体开通微信云开发，并取得环境 ID。根据实际控制台核验可用的 Node.js 20 或更高 LTS 运行时。
2. 创建 `assistant_users` 和 `assistant_budgets` 两个集合。小程序客户端的直接读写权限均设为拒绝，仅允许受控服务端访问。
3. 为 `assistant_users.updatedAt` 建立升序索引；清理任务每次处理最久未维护的50个用户，注意监控积压。
4. 本项目的数据库访问规则不能仅靠前端判断。逐条验收两个不同微信测试账号之间的隔离。
5. 构建 `pnpm build`，在微信开发者工具中对 `assistantApi` 和 `assistantCleanup` 分别执行上传部署并安装依赖；上传云函数是你授权后才执行的外部操作，本次尚未执行。
6. 云函数 SDK 依赖见部署包 package.json。部署安装应记录实际解析版本，并在生产上线前锁定验证过的版本。

云端仓库使用 SDK 的事务接口，已通过契约模拟测试；实际 SDK 行为、首次文档创建、事务冲突及权限，必须完成云端验证才能算接入完成。

## 三、服务端环境变量

参考仓库 `.env.example`。该文件不会自动上传或自动导入；请在云函数环境变量或受控密钥设施中填写。

必填项目：

```text
ASSISTANT_USER_HASH_SECRET=<至少32字符随机值>
MODEL_API_URL=<实际服务的HTTPS Chat Completions完整地址>
MODEL_API_KEY=<你自己填写>
MODEL_NAME=<实际开通的模型ID>
MODEL_JSON_MODE=true
MODEL_THINKING=disabled
MODEL_TIMEOUT_MS=20000
TENCENT_SECRET_ID=<最小权限服务端凭证>
TENCENT_SECRET_KEY=<你自己填写>
TENCENT_REGION=ap-guangzhou
TMS_BIZ_TYPE=<已开通的文本审核策略>
DAILY_MODEL_CALL_LIMIT=100
PROVIDER_NAME=<实际模型供应商与模型名称>
OPERATOR_NAME=<实际运营主体>
SUPPORT_CONTACT=<投诉联系渠道>
ASSISTANT_ENABLED=false
```

临时凭证另填 `TENCENT_SESSION_TOKEN`，并负责其有效期管理。当前代码只读取上述显式凭证，不会自动假设云函数角色凭证可用于 TMS；如要改用运行角色，需另外实现并测试凭证提供器。

本项目按用户确认的平台使用以下服务端默认值：

```text
MODEL_API_URL=https://open.bigmodel.cn/api/paas/v4/chat/completions
MODEL_NAME=glm-4.7
MODEL_JSON_MODE=true
MODEL_THINKING=disabled
PROVIDER_NAME=智谱 BigModel · GLM-4.7
```

官方地址和模型 ID 见 [智谱 GLM-4.7 文档](https://docs.bigmodel.cn/cn/guide/models/text/glm-4.7)，认证与JSON参数见 [官方对话补全文档](https://docs.bigmodel.cn/api-reference/模型-api/对话补全)。不使用 Coding 专用端点，不假设编程套餐额度可用于本小程序；在平台核验通用API权限、可用余额及账单。

短回复默认关闭思考并限制 `max_tokens=1024`；这是本项目的延时与输出长度取舍，不保证模型总能在20秒内完成。切换其他供应商时重新核验模型ID、接口和参数；`MODEL_THINKING=default` 表示省略该供应商专用参数，不能把智谱密钥发给其他服务。

若实际模型不支持 `response_format`，在验证后设 `MODEL_JSON_MODE=false`；系统提示词仍要求JSON，服务端继续进行严格结构与输出审核。不自动关闭审核以追求联通。

### 本机独立接口诊断（不等于真实用户验收）

`node scripts/model-smoke.mjs` 从当前进程的 `MODEL_API_KEY` 读取密钥，固定只向上述智谱官方地址发一次合成消息，不自动重试，不读真实聊天，不上传云函数。它不会自动读取`.env`，也不会把密钥写入文件。不要把密钥放进可共享的命令示例或截图。

本机 Node fetch 两次连接尝试未完成，其中一次确认 `UND_ERR_CONNECT_TIMEOUT`；系统HTTP客户端独立请求成功，用量308 tokens。正式项目提示词的真实响应却返回 `warnings:[{text:...}]`，被严格Schema拦截，不能标为业务成功。已补充“warnings必须是字符串数组”和不虚构拒绝理由／后续承诺的提示词；新增不扣体验额度、不保存历史的回归测试，修订后尚未真实复测。

Windows可选诊断：设置当前进程 `MODEL_SMOKE_TRANSPORT=windows` 后运行同一脚本。它调用已安装的 PowerShell 7 发送相同项目请求，仅是本机网络排查工具；生产云函数仍使用 Node fetch，没有偷偷更换生产传输或放宽输出校验。诊断脚本的字节数组类型和控制台UTF-8编码问题已经修复；较早乱码输出不能用于文字质量评测。

最近诊断产物保存在 `.local/glm-smoke-20261018/latest.json`，只含合成响应、结构问题和用量，不含密钥。模型请求即使最终被业务校验拒绝，也可能产生供应商费用；“不扣体验额度”不等于“模型调用免费”。

## 四、清理任务

`assistantCleanup/config.json` 提供每15分钟的定时触发配置示例，按实际控制台核验并部署。处理程序拒绝带可信小程序 OPENID 的客户端调用，只接受定时事件格式；还需通过云端调用权限将它限制为调度器和受权管理员可调用。

清理会终结过期任务并去除超过1小时的临时正文、超过48小时的任务墓碑、超过30天的历史与超过90天的反馈。即使清理滞后，业务查询也会在返回前进行过期检查。监控每轮处理数量及最旧 updatedAt，用户量增加时提高处理能力，不能把每15分钟触发误认为所有用户都能在15分钟内清理。

本项目尚未配置实际云备份及销毁周期，不承诺第三方模型供应商的数据删除时效。公开发布前确认和披露实际情况。

## 五、在小程序中切换

1. 填写 `src/miniprogram/config.ts` 的 `cloudEnvId`，填写根配置的企业 AppID。
2. 执行 `pnpm check`，重新编译。
3. 在云端确认模型及审核服务均可用后，设置 `ASSISTANT_ENABLED=true`。
4. 小程序“我的 → 开发与接入 → 运行模式”选择真实模型。默认仍保持本地模拟，避免误调用。
5. 使用合成聊天进行一次生成，核对三条结果、标识、用量、费用和审核链路。
6. 切回模拟模式不清除云端数据；若要删除，需在云端模式执行相应删除动作。

不需要把 API Key 写入小程序，也不需要关闭开发者工具的合法域名校验。

## 六、必须完成的真实验证

- 企业 AppID 能正常调用目标云函数，可信 OPENID 来自服务端上下文。
- 云函数依赖安装、Node运行时、数据库事务、首次创建和索引工作正常。
- 模型请求成功，返回完整 JSON；当前只支持非流式 Chat Completions 兼容响应。
- 模型／审核失败时不会向用户泄漏原始错误、密钥或未审查输出。
- 两个真实测试账号互相无法访问对方记录，伪造 userId／openid 无效。
- 网络超时重试相同请求编号不重复调用模型；供应商实际调用计数可核对。
- 删除中有进行中的生成请求时，晚到结果无法恢复已删除业务数据。
- 定时清理确实被触发，旧正文得到物理清理，积压被监控。
- 体验额度、频率限制、当日调用硬上限与供应商账单口径一致且有告警。
- 正式隐私文本、运营主体、类目、备案登记和合作证明已确认。

这些事项完成前，状态应标为“内部开发联调”，不能标成“已正式上线”。
