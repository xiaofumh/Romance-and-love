# V0.1 真实用户验收清单

状态：进行中，未通过完整验收。2026-10-18。

原则：使用合成资料、真实页面和真实接口。页面渲染、独立模型HTTP调用、云端全链路和真机是不同层级，不混算。系统登录／权限由用户自行完成；不读取个人微信消息，不发送消息、不发布小程序。

| 场景 | 真实用户操作与通过标准 | 当前状态 |
| --- | --- | --- |
| 首次进入 | 默认关闭历史和记忆；未同意使用时不能生成 | 原生通过 |
| 手动输入 | 输入消息，选择场景／语气，勾选说明，生成3条建议 | 原生模拟模板通过，真实云端未测 |
| 输入边界 | 空消息、超长、背景与目标合计超限，提示可理解且不发无效模型请求 | 自动逻辑通过，原生边界待补 |
| 事实忠实 | “不想参加”不能变成加班／生病／没时间，不替用户承诺再约，不断定对方动机 | 初步真实样例不合格；提示词已加强，真实复测待做 |
| 结果结构 | 3条不同建议；warnings为字符串数组；不完整／异常输出不放行、不保存历史、不扣体验额度 | 异常真实响应被拦截；回归测试通过 |
| 编辑复制 | 编辑后实际复制并粘贴，文字一致且只含一个AI标识；取消编辑不更改结果 | 编辑原生通过；真实剪贴板待确认，不能以mock回调替代 |
| 历史确认 | 在原生确认框取消不保存；确认后只保存后续生成，进入历史可展开并复制 | 有替身流程通过；无替身原生弹窗等待用户点击 |
| 档案与记忆 | 新建别名档案，事实需单独确认，编辑需再次确认；未选档案不使用其记忆 | 原生+逻辑覆盖，但部分应用确认框此前有替身；完整无替身待补 |
| 删除与撤回 | 仅删合成测试记录；取消不删，确认后晚到结果不复活；撤回停止后续生成 | 后端回归通过；真实确认／云端竞态待补 |
| 超时与重试 | 断网／超时提示明确，相同请求ID查询不重复调用；实际调用次数可对账 | 自动逻辑通过，云端网络／账单待验 |
| 配额与费用 | 成功才扣体验额度；失败仍可能有供应商费用；限频与每日调用硬上限可核对 | 自动逻辑通过；供应商实际费用对账待验 |
| 身份隔离 | 两个真实微信测试账号互访记录均被拒绝，不信任客户端传入openid | 自动逻辑通过，真实账号待验 |
| 持久化与清理 | 关闭重开、跨天和真机记录符合授权；过期数据经定时任务物理清除 | 云端未部署，不能用模拟器会话证明 |
| 真实模型链路 | 小程序 → 可信OPENID云函数 → 审核 → GLM → 输出校验／审核 → 结果页 | 缺云环境ID与服务端审核配置，未接通 |

## 继续测试需要

1. 微信云开发环境 ID、确认企业AppID、授权后的云端部署；模型与文本审核密钥仅填服务端。
2. 当前模拟器“开启历史保存？”弹窗请用户点击一次；官方原生确认命令没有实际关闭该弹窗，不改用伪造确认。
3. 至少两个微信测试账号及真机配合；系统权限／登录由用户手动操作。
4. 模型费用与单轮最大调用次数由用户确认后再做批量质量评测，当前不启动无限重试或自动批量付费调用。
