## 2. 服务端变量，密钥不发聊天

在assistantApiV2的服务端环境变量中填写；本地.env.example不会自动变成云端配置。

| 项目 | 值或要求 |
| --- | --- |
| ASSISTANT_ENABLED | 先设false，完成下列配置与非生成检查后才设true |
| ASSISTANT_USER_HASH_SECRET | 安全生成并保存至少32字符的随机密钥，建议64字符；用于用户隔离，后续不要随意更换 |
| MODEL_API_KEY | 智谱BigModel国内官方的新密钥；此前发到聊天里的密钥应先轮换 |
| MODEL_API_URL | https://open.bigmodel.cn/api/paas/v4/chat/completions |
| MODEL_NAME | glm-4.7 |
| MODEL_THINKING | disabled |
| MODEL_TIMEOUT_MS | 20000 |
| TMS_BIZ_TYPE | 腾讯文本内容安全中实际创建的审核策略标识 |
| TENCENT_SECRET_ID / TENCENT_SECRET_KEY | 具备所需文本审核调用权限的最小权限服务端凭证；不是微信AppSecret |
| TENCENT_SESSION_TOKEN | 仅使用临时凭证时填写，并维护过期时间 |
| TENCENT_REGION | ap-guangzhou，或与审核服务配置一致的支持区域 |
| DAILY_MODEL_CALL_LIMIT | 建议首轮冒烟测试先设10；这是全站模型请求次数上限，不是人民币预算 |
| CHAT_DAILY_USER_LIMIT | 建议首轮先设5；正式做50轮前需结合当日已有用量提高 |
| OPERATOR_NAME / SUPPORT_CONTACT | 实际运营主体和投诉联系渠道，公开测试/发布前不能保留占位文字 |

没有内容审核配置时，当前实现拒绝真实生成；不以关闭审核或假审核替身代替生产测试。购买云环境不代表模型和审核服务已分别配置或包含在同一费用中。

## 3. 数据库与访问权限

由管理员在该目标环境创建assistant_users、assistant_budgets两个集合，设为客户端不可直接读写（服务端专用）。权限操作需用户手动确认，不自动放宽为所有用户可读写。

真实用户身份由云函数从微信可信上下文读取；客户端不能指定其他用户ID。数据库集合规则只是其中一层保护，仍需验证服务端事务、资源归属和删除行为。两个真实微信账号尚未验收，不能用本地模拟用户隔离测试替代。

assistant_users的updatedAt升序索引用于后续定时清理。定时清理函数尚未部署；完成数据库、保留期限和删除验证后再启用，不应在长期保存真实资料时遗忘此步骤。

## 4. 分阶段验收

1. 先确认运行时20、超时45秒、云端依赖安装完成；不通过控制台伪造OPENID来模拟微信用户。
2. 配置完成且ASSISTANT_ENABLED=false时，从小程序真实微信上下文调用bootstrap，核对数据库事务和可信身份。非生成接口也可能有正常云资源费用。
3. 用户阅读并手动确认当前使用说明、聊天保存和资料导入授权；不自动点击隐私同意。
4. 服务端开启模型后先做3轮合成内容冒烟测试，验证输入审核、GLM回复、输出审核和幂等重放。不能把服务关闭/配置错误的返回当作聊天通过。
5. 冒烟通过后再跑50轮；提高当日全站/单用户上限以容纳已有用量。记录真实模型请求次数、失败及token用量，失败调用也可能计费，不自动无限重试。
6. 使用第二个真实微信账号验证隔离；资料撤回、角色删除、历史删除及并发请求分别验证。当前未完成这些步骤。

测试资料优先用合成内容。本地ZIP中的数据此前识别为第三方合成/公开数据集，不是用户真实微信聊天记录；未经授权不上传其他人的私人聊天。保持模型身份在界面可见，正文可代入角色，但不能冒充真实联系人。
