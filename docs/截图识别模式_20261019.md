# V0.2.6 截图识别模式

入口：角色资料的导入页 → 截图识别 → 相册选一张图 → 独立上传授权 → 真实识别 → 逐页改字/选左右归属/排除占位和重复 → 核对确认 → 加入原导入页 → 文本清洗预览 → 最终资料权利授权。

截图上传是新的数据处理方式，不等于TXT本地解析。识别原图可能含姓名、头像等第三人信息，需先裁掉不需要的内容；图片未经识别前不能承诺已脱敏。不获取联系人列表或其他微信聊天，不会代读后台聊天。

## 技术与边界

更新：免费GLM-4.6V-Flash返回1305拥堵后，用户明确选择“允许使用按量计费视觉模型”，当前识别固定改用GLM-4.6V-FlashX。页面及隐私说明同步标记按量计费；不自动切换其他模型。以下免费模型试验记录保留作为历史，不代表当前默认。

- 云函数仍为assistantApiV2，新增screenshot.recognize，复用服务端MODEL_API_KEY，不向客户端透露密钥。
- 仅识别调用用户授权的GLM-4.6V-FlashX，聊天GLM-4.7保持不变，不自动切换其他模型。官方当前价格页按输入长度区分输入/输出Token费用，云资源另有成本、账号仍可能限流或未开通，次数上限不等于人民币金额上限。
- 原图≤8MiB、≤2400万像素；本地Canvas2D等比例缩到≤900像素宽，长图按≤2600像素高、160像素重叠切片，最多6片。每片JPEG编码≤512KiB，必要时降低编码质量但不无限缩小；仍过大时明确要求裁剪。画布用后释放。
- 分片保留重叠，可能重复或裁断文字；不自动删除重复，不假设左右就是用户身份。只有用户核对，模型uncertain标记不是可信准确率。
- 图片/表情包/语音/视频只记nontext占位，不臆造转录；需排除或手工补充核实文字。引用内容、背景文字、导航/状态栏要求模型忽略，仍需验收。
- 单片最多120条候选，输出超过/截断/无效JSON均拒绝，不能假装完整。
- 每用户每天10次分片尝试（含失败），与聊天共享已有全局模型调用预算；不占聊天30轮计数。失败不自动重试；重试按钮是新增一次主动尝试，仅重试失败分片。
- 可信微信身份、角色归属、通用使用同意、截图专门授权、开关及白名单先校验；原始payload不接受外部图片URL或用户ID。当前有独立文本审核的公开路径尚未完成图片审核接入，截图功能在该路径失败关闭，不以白名单开发版本当公开上线。
- 应用云端不持久保存原图/OCR正文；48小时仅保留HMAC摘要、编号、时间和状态，防重复和限额。识别数据只在当前页面等待核对，离开清理；已向服务商发出的在途请求不能撤回。图片Base64不进入数据库、日志或报告。
- 用户修改内容、归属、排除项或更换图后撤销旧核对。返回导入页只加入已核对脱敏文字，不自动保存或授权。原TXT保留，不覆盖。

## 验证

单元及页面测试使用合成文字/PNG和SDK替身，覆盖长图完整分片、图片大小与类型、防伪造身份、角色隔离、独立授权、撤回、重复与预算、仅重试失败片、不保存图片或OCR正文、非文字与未知归属门槛、修改后取消核对。实际样图验收及部署结果另记在交付文件，不把模拟测试当成真实识别成功。

2026-10-19真实开发工具Canvas验收：用户提供1260×9998、2243652字节长图，本地生成3个JPEG片，分别399210、425676、380862字节，均未超512KiB，原图未修改。assistantApiV2部署成功，沿用已有配置。

真实视觉接口首片返回OCR_UNAVAILABLE；增加白名单化错误码后再次请求，确认HTTP429、业务1305。按官方错误码 https://docs.bigmodel.cn/cn/api/api-code ，1305表示该模型当前访问量过大，而非欠费1113或认证1000。当前不能宣称真实识别成功、字准率或完整提取。应用提示拥堵，阻止一分钟内连续重试，不自动转收费模型。聊天剩余额度读取仍为30。开发工具验收临时拷贝用后清理，相册原图不删除。实际供应商返回过错误请求，不能据此声称供应商未收到任何图片。

原生相册选择未由自动化代用户操作：验收把用户明确提供的样图复制到开发工具本地临时目录，复用真实prepareImage/Canvas流程及可信wx.cloud调用；未改动页面上传或核对勾选，未保存角色资料。更换预览或真机相册仍需用户授权验收。

最终实际按量模型复测：修复完整JSON代码围栏兼容、区分返回校验阶段，并将长时间API验收改为异步发起/短查询读取（避免自动化桥等待超时被误当成服务失败）。用户给定长图的3片全部成功，共50条候选，分别18/20/12条；6条unknown归属、3条nontext占位。末片包含样图末尾文字的检测点，未检出背景LOOK RIGHT标记，但不据此宣称字准率、无漏字或所有背景/引用均排除。候选含重叠，不等于50条独立真实消息。原生核对页已截图检查，未确认上传/结果复核框、未导入角色资料；个人聊天剩余调用前后均为30。

测试失败会计入当天尝试；bootstrap和截图页现显示本人剩余识别分片数，不虚构预算或重置计数。次数不是人民币金额上限，真实费用以供应商账单为准。
